## Estrutura do repositório

- `index.html` — a página do site
- `trilha.css` — identidade visual da trilha (tema “castelo”, comum a todos os sites)
- `trilha.js` — realce de código GDScript e botão “copiar”
- `img/` — sprites, telas do jogo modelo e ícones
- `Modelo_GDD_1_Pagina.docx` — modelo de GDD da trilha

## Publicar no GitHub Pages

1. Crie o repositório público `GameDev2D-C1-02` na conta `rclepf`.
2. Envie todo o conteúdo desta pasta para a raiz do repositório (o `index.html` precisa ficar na raiz).
3. Em **Settings → Pages**, escolha **Deploy from a branch → `main` / `(root)`** e salve.
4. Em 1 a 2 minutos o site fica disponível em `https://rclepf.github.io/GameDev2D-C1-02/`.

## Testar no computador antes de publicar

Basta abrir o `index.html` no navegador (duplo clique) ou servir a pasta com `python -m http.server 8000`.
